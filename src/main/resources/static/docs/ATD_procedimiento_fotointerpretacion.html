Procedimiento — Fotointerpretación de alertas tempranas

Mini manual operativo para validar alertas en campo y oficina.

1. Preparación

  1. Abrir el reporte PDF y, si existen, las imagenes exportadas desde H2.
  2. En el enlace Visualizacion del PDF, abrir el Dashboard ACR de monitoreo de deforestacion.
  3. Contrastar con el mapa de ubicación (ACR, zona de influencia y punto de alerta).

2. Criterios de interpretación

  • Antrópico: agricultura, ganadería, minería, infraestructura, ocupación humana.
  • Natural: inundación, deslizamiento, muerte natural de árboles.
  • Falsa alerta: nubes, sombras, cambios espectrales temporales.

3. Pasos de validación

  1. Confirmar que el polígono coincide con pérdida de cobertura forestal visible.
  2. Estimar superficie afectada y comparar con el valor del sistema (ha).
  3. Asignar causa dominante según dominio GeoBosques / GDB.
  4. Registrar nivel de confiabilidad (alta / media / baja).
  5. Documentar observaciones para seguimiento en campo si aplica.

4. Uso de imágenes Sentinel-2

  • Combinación color natural (B04, B03, B02) para lectura visual.
  • Comparar fechas de escena antes y después del evento reportado.
  • Usar swipe en EO Browser para deslizar entre fechas.

5. Entregables

Reporte PDF firmado, capas en GDB actualizadas y registro en monitoreo acumulado.
